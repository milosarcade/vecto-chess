# Vecto Chess

Play chess against Vecto, an alpha-beta engine that runs entirely in your
browser. No server and no download: the engine thinks in a web worker on your
own machine.

Play it: https://milosarcade.com/vecto-chess/

## Features

- Six strengths, from **Learner** to **Full strength**
- Play White, Black or a random side, and switch sides mid-game
- **Hint** asks the engine for a suggestion
- **Undo** takes back your last move, **Flip** turns the board
- Live engine readout: evaluation, search depth, nodes, speed and the line it expects
- Copy the game as **PGN** or the position as **FEN**
- Light and dark themes

Use the left and right arrow keys to step back and forward through the moves.

A single HTML file, no build step. Served with GitHub Pages.
